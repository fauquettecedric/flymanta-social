# Flymanta – visuels réseaux sociaux

Visuels publics des posts Flymanta (Instagram, LinkedIn). Ce dépôt sert d'hébergement pour Metricool.

- `semaines/AAAA-MM-JJ/` : visuels de la semaine (date du lundi).
- `profil/` : photo de profil Instagram, logo et bannière LinkedIn.
- `templates/` : modèles HTML aux couleurs Flymanta et script de rendu (`node templates/render.mjs <html> <sortie>`).

Charte : fond #071A21, crème #F3EEE4, orange #FF9466, vagues #0F3A47 / #0B2C36. Titres Space Grotesk 600, texte Inter. Format Instagram 1080 × 1350.
